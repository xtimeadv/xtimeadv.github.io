Cấu Hình Tự Động Đồng Bộ GitHub API

Tự động đẩy file data.json lên GitHub Repository để lưu trữ vĩnh viễn.

Hướng dẫn kết nối vĩnh viễn với xtimeadv.github.io:

  1. Username: Điền xtimeadv
  2. Repository: Điền xtimeadv.github.io
  3. Branch: Điền main hoặc master
  4. GitHub Personal Access Token (PAT): Tạo token tại GitHub -> Settings -> Developer settings -> Personal access tokens (classic) tích chọn quyền repo.

Mã token này sẽ được lưu an toàn trên trình duyệt của bạn để tự động đẩy dữ liệu lên GitHub.
